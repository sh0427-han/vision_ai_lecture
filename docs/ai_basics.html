신경망은 어떻게 학습할까?

CNN을 보기 전에 Weight가 무엇이고, 왜 비선형성이 필요하며, Loss와 Backpropagation이 어떻게 Dataset에서 학습으로 이어지는지 이해합니다.

Dataset → Forward → Loss → Backpropagation → Weight Update → Feature Learning
1

AI 모델은 결국 숫자를 바꾸는 함수

Input x ↓ Model f(x; θ) ↓ Prediction ŷ
Parameter학습 과정에서 값이 바뀌는 숫자입니다.
Weight입력을 얼마나 반영할지 결정하는 대표적인 Parameter입니다.
y = wx + b
2

왜 비선형성이 필요한가?

Activation Function 없이 Affine Layer만 여러 개 쌓으면 전체를 다시 하나의 Affine Transformation으로 합칠 수 있습니다.

3

Activation Function이 깊은 네트워크를 의미 있게 만듭니다

Activation FunctionLayer 출력에 비선형 변환을 추가하는 함수입니다.
ReLU(x) = max(0, x) [-2, -0.5, 0, 1, 3] ↓ [ 0, 0, 0, 1, 3]
Linear ↓ ReLU ↓ Linear ↓ ReLU ↓ Linear

현대 모델에서는 ReLU 외에도 GELU, SiLU 같은 Activation을 사용합니다.

4

Feature와 Representation

모델의 목표는 Pixel을 그대로 외우는 것이 아니라 문제 해결에 유용한 내부 표현을 만드는 것입니다.

Feature문제를 푸는 데 유용한 특징입니다.
Representation입력을 모델 내부에서 다시 표현한 숫자 형태입니다.
Raw Pixel ↓ Edge / Texture ↓ Shape ↓ Task에 유용한 Representation
5

“학습”은 Weight를 반복 수정하는 과정

6

Forward → Loss → Backpropagation → Optimizer

Forward현재 Weight로 Prediction을 계산합니다.
LossPrediction과 정답 Label의 차이를 수치화합니다.
GradientParameter 변화가 Loss에 미치는 방향과 크기입니다.
BackpropagationLoss에서 시작해 각 Parameter의 Gradient를 계산합니다.
new_weight = old_weight - learning_rate × gradient
7

Learning Rate, Batch, Epoch

용어의미예시
Learning Rate한 번 Update할 때 Weight를 얼마나 크게 움직일지 결정0.001
Batch한 번의 Forward/Backward에 함께 사용하는 샘플 묶음32 images
EpochTrain Dataset 전체를 한 번 모두 사용한 횟수30 epochs
Learning Rate가 너무 크면 학습이 불안정할 수 있고, 너무 작으면 학습이 지나치게 느릴 수 있습니다.
8

Dataset은 모델이 배우는 세상

9

Train / Validation / Test

Train실제로 Weight를 Update하는 데이터입니다.
Validation모델 선택, Hyperparameter 조정, Early Stopping 등에 사용합니다.
Test최종 일반화 성능을 평가하기 위해 가능한 한 독립적으로 유지합니다.
Data Leakage
평가 시 알면 안 되는 정보가 Train 과정에 들어가 성능이 실제보다 좋아 보이는 문제입니다.
같은 원본 영상 Train: frame_001 Test : frame_002 → 거의 같은 장면이면 평가가 왜곡될 수 있음
10

Overfitting과 Data Augmentation

상태TrainVal/Test
Underfitting낮음낮음
적절한 학습높음높음
Overfitting매우 높음상대적으로 낮음
Data AugmentationFlip, Crop, 밝기, Blur 등으로 Train Data를 변형해 다양한 조건을 경험하게 합니다.
주의: 실제 Task 의미를 깨뜨리는 증강은 오히려 학습을 방해할 수 있습니다.
11

이제 CNN을 보면 다르게 보입니다

Image Tensor ↓ Convolution ↓ Activation ↓ Feature ↓ Convolution ↓ Prediction

Kernel은 고정된 규칙이 아니라 Dataset에서 학습되는 Weight입니다.

Forward → Loss → Backpropagation → Optimizer의 학습 원리가 CNN에도 그대로 적용됩니다.
