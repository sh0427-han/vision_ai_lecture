AI, Machine Learning, Deep Learning은 어떻게 다를까?

Computer Vision은 이미지·영상 문제를 다루는 분야이고, 그 문제를 해결하기 위해 전통적 영상처리, Machine Learning, Deep Learning을 모두 사용할 수 있습니다.

정답 Label이 있느냐에 따라 학습 방식이 달라집니다

Supervised Learning(지도학습)은 입력과 정답을 함께 보며 관계를 배우고, Unsupervised Learning(비지도학습)은 정답 Label 없이 데이터의 구조와 패턴을 찾습니다.

Vision AI에서 가장 흔한 출발점: 정상/불량 Classification, Bounding Box Detection, Pixel Mask Segmentation처럼 정답 Label을 이용하는 문제는 지도학습입니다. 비지도학습은 Label이 부족할 때 데이터 구조 탐색, 군집화, Representation 학습 등에 활용할 수 있습니다.

Linear Regression으로 “학습”을 가장 단순하게 보자

입력과 정답의 관계를 가장 잘 설명하는 직선을 찾는 문제입니다. 모델이 학습하는 값은 기울기와 절편입니다.

Linear Regression Model
y^ = wx + b
x 입력 y^ 예측값 w 기울기 b 절편
처음에는 임의의 w, b에서 시작하고, 예측 오차가 줄어들도록 두 Parameter를 반복해서 수정합니다.
8

Loss Function은 “얼마나 틀렸는지”를 하나의 숫자로 만듭니다

Regression에서는 예측값과 정답의 차이를 제곱해 평균낸 MSE를 대표적인 Loss Function으로 사용할 수 있습니다.

Mean Squared Error
MSE = 1 N ∑ i=1 N ( yi − y^i ) 2

N개 Sample의 정답 − 예측값을 제곱한 뒤 평균합니다.

Loss가 크다 → 현재 직선이 데이터와 잘 맞지 않음
Loss가 작다 → 예측이 정답에 가까움

학습의 목표는 Loss를 더 작게 만드는 Parameter를 찾는 것입니다.
9

Optimizer는 Loss가 낮아지는 쪽으로 Parameter를 이동시킵니다

Gradient는 Loss가 증가하는 방향을 알려줍니다. Optimizer는 그 반대 방향으로 Weight와 Bias를 조금씩 수정합니다.

새 Parameter=현재 Parameter−Learning Rate × Gradient
10

신경망의 가장 단순한 계산을 Perceptron으로 이해해 봅시다

Perceptron 계산
z= wTx +b
y^ = f(z)

입력의 Weight를 곱해 더한 값 z에 Activation Function f를 적용해 출력을 만듭니다.

11

AND는 직선으로 나뉘지만, XOR는 직선 하나로 나눌 수 없습니다

이 차이가 “왜 Neural Network에 비선형 Activation이 필요한가?”로 이어집니다.

핵심: Linear Model 하나는 직선 경계만 만들 수 있습니다. XOR처럼 더 복잡한 경계를 표현하려면 비선형성이 필요합니다.
12

Linear Layer만 여러 개 쌓아도 결국 하나의 Linear 변환과 같습니다

중간에 Activation이 없다면 여러 Affine Transformation은 다시 하나의 Affine Transformation으로 합쳐집니다.

Linear 1W₁x + b₁
→
Linear 2W₂h + b₂
→
하나의 Linear LayerW*x + b*
W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)
따라서 XOR처럼 비선형 결정 경계가 필요한 문제에는 Activation Function이 필요합니다.
13

Activation Function이 비선형성을 추가합니다

Linear Layer 사이에 ReLU 같은 비선형 함수를 넣으면, 여러 Layer를 조합해 더 복잡한 Decision Boundary를 만들 수 있습니다.

ReLU: 음수는 0, 양수는 그대로 통과시키는 단순한 함수지만 Network 전체에는 중요한 비선형성을 제공합니다.

Data Leakage는 평가할 때 몰라야 하는 정보가 새어 들어간 경우입니다

Validation/Test 성능이 실제보다 좋아 보일 수 있기 때문에 Split 이후의 정보 흐름을 엄격히 관리해야 합니다.

이미지·영상은 Random Frame Split보다 원본 단위 분리가 안전합니다

같은 영상·설비·대상·시간대에서 나온 Sample은 서로 강하게 연관되어 있을 수 있습니다.

데이터를 K개 Fold로 나누고 매번 하나를 Validation으로 사용해 K번 학습합니다. 같은 Metric의 평균과 Fold 간 변동을 함께 봅니다.

최종 Test Set은 Cross Validation 바깥에 별도로 유지하는 것이 일반적

이미지·영상처럼 Group 상관관계가 강하면 일반 K-Fold 대신 Group K-Fold처럼 Group을 통째로 이동시키는 방식이 더 적절할 수 있습니다.

28

목표는 Train 점수가 아니라 새로운 데이터에서의 성능입니다

Train에 지나치게 맞는 Overfitting을 피하고, 보지 못한 데이터에서도 성능이 유지되는 Generalization을 확인해야 합니다.

29

실제 AI 개발은 운영 결과를 다시 Data로 연결하는 반복 Cycle입니다

Training 한 번으로 끝나는 것이 아니라, Deploy 후 실패 사례를 Monitor하고 다음 Dataset과 학습에 반영합니다.
