Lecture 02

AI 기초: 신경망은 어떻게 학습하는가?

CNN과 ViT를 보기 전에 모델의 Weight가 어떻게 학습되고, 왜 비선형성과 Dataset이 중요한지 먼저 이해합니다.

1. 모델은 결국 숫자를 바꾸는 함수

Input x ↓ Model f(x; θ) ↓ Prediction ŷ
Parameter / Weight학습 과정에서 값이 바뀌는 숫자입니다. y = wx + b에서 w와 b가 대표적인 학습 대상입니다.

2. 왜 비선형성이 필요한가?

Linear/Affine Layer는 보통 y = Wx + b 형태입니다. Activation Function 없이 이런 Layer만 여러 개 쌓으면 전체를 다시 하나의 Affine Transformation으로 합칠 수 있습니다.

핵심: 현실의 이미지 문제는 직선이나 평면 하나로 설명하기 어려운 복잡한 관계를 가지므로 비선형성이 필요합니다.

3. Activation Function

Activation FunctionLayer 출력에 비선형 변환을 추가해 깊은 네트워크의 표현력을 높이는 함수입니다.
ReLU(x) = max(0, x) [-2, -0.5, 0, 1, 3] ↓ [ 0, 0, 0, 1, 3]

현대 모델에서는 ReLU뿐 아니라 GELU, SiLU 같은 함수도 사용합니다.

4. Feature와 Representation

Feature문제를 푸는 데 유용한 특징입니다.
Representation입력을 모델 내부에서 문제 해결에 유용한 숫자 형태로 바꾼 표현입니다.
Raw Pixel ↓ Edge / Texture ↓ Shape ↓ Task에 유용한 Representation

5. 학습은 Weight를 반복해서 수정하는 과정

Forward현재 Weight로 Prediction을 계산합니다.
LossPrediction과 정답 Label 사이의 차이를 수치화합니다.
GradientParameter를 바꿀 때 Loss가 어느 방향으로 변하는지 나타냅니다.
BackpropagationLoss에서 시작해 각 Parameter의 Gradient를 뒤에서 앞으로 계산합니다.
OptimizerGradient를 이용해 Weight를 실제로 업데이트합니다.
new_weight = old_weight - learning_rate × gradient

6. Learning Rate, Batch, Epoch

용어의미예시
Learning Rate한 번 Update할 때 Weight를 얼마나 크게 움직일지 결정0.001
Batch한 번의 Forward/Backward에 함께 넣는 샘플 묶음32 images
EpochTrain Dataset 전체를 한 번 모두 사용한 횟수30 epochs

7. Dataset은 모델이 배우는 세상

모델은 우리가 제공한 데이터에서 패턴을 배우기 때문에 Architecture만큼 데이터의 다양성, Label 품질, 운영 환경 대표성이 중요합니다.

Train실제로 Weight를 업데이트하는 데이터입니다.
Validation학습 중 모델 선택과 Hyperparameter 조정에 사용하는 데이터입니다.
Test최종 일반화 성능을 평가하기 위해 가능한 한 독립적으로 유지하는 데이터입니다.

8. Data Leakage

Data Leakage평가 시 모델이 알면 안 되는 정보가 Train 과정에 들어가 성능이 실제보다 좋아 보이는 문제입니다.

예를 들어 같은 영상에서 나온 거의 동일한 연속 Frame이 Train과 Test에 동시에 들어가면 새로운 영상에 대한 성능보다 Test 결과가 지나치게 좋아질 수 있습니다.

9. Overfitting과 Underfitting

상태TrainValidation / Test
Underfitting낮음낮음
적절한 학습높음높음
Overfitting매우 높음상대적으로 낮음
Data AugmentationFlip, Crop, 밝기 변화처럼 Train Data를 변형해 다양한 조건을 경험하게 하는 방법입니다. 실제 문제의 의미를 깨뜨리지 않는 범위에서 사용해야 합니다.

10. 이제 CNN을 보면

Image Tensor ↓ Convolution ↓ Activation Function ↓ Feature ↓ Convolution ↓ Activation Function ↓ Prediction Kernel Weight는 Forward → Loss → Backpropagation → Optimizer 과정으로 Dataset에서 학습된다.
이제 CNN의 Kernel을 “고정된 필터”가 아니라 Dataset을 통해 학습되는 Weight로 볼 수 있습니다.
