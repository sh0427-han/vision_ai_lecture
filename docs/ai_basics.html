AI, Machine Learning, Deep Learning은 어떻게 다를까?

Computer Vision은 이미지·영상 문제를 다루는 분야이고, 그 문제를 해결하기 위해 전통적 영상처리, Machine Learning, Deep Learning을 모두 사용할 수 있습니다.

3

분류와 회귀

Classification은 범주를, Regression은 연속적인 숫자 값을 예측합니다.

4

Linear Regression으로 “학습”을 가장 단순하게 보자

입력 x와 정답 y가 있을 때, 데이터에 가장 잘 맞는 직선 ŷ = wx + b의 기울기 w와 절편 b를 찾는 문제입니다.

모델이 배워야 할 값
w, b

w : 직선의 기울기
b : 직선의 시작 위치

처음에는 임의의 직선에서 시작하고, 예측이 틀린 정도를 보고 w와 b를 조금씩 수정합니다.
5

Loss Function은 “얼마나 틀렸는지”를 하나의 숫자로 만듭니다

Regression에서는 예측값 ŷ와 정답 y의 차이를 제곱해 평균낸 MSE를 가장 기본적인 예로 볼 수 있습니다.

Mean Squared Error
MSE = mean((y - ŷ)²)

Loss가 크다 → 현재 직선이 데이터와 잘 맞지 않음
Loss가 작다 → 예측이 정답에 가까움

학습의 목표는 단순합니다. Loss가 더 작아지는 Parameter를 찾는 것입니다.
6

Optimizer는 Loss가 줄어드는 방향으로 Parameter를 바꿉니다

Gradient는 “어느 방향으로 얼마나 바꾸면 Loss가 증가하는가”를 알려주고, Optimizer는 그 정보를 이용해 w와 b를 업데이트합니다.

반복: 예측 → Loss 계산 → Gradient 계산 → Parameter 수정. 이 루프가 AI 학습의 핵심 뼈대입니다.

이진 분류와 다중 클래스 분류

Binary Classification두 선택지 중 하나를 고릅니다.
raw score ↓ Sigmoid ↓ Abnormal = 0.87

Sigmoid와 Softmax는 모델의 출력 점수를 해석하기 쉬운 값으로 바꾸는 데 자주 사용됩니다.

신경망의 기본 단위: Perceptron

10

AND Gate — 직선 하나로 구분할 수 있는 문제

AND 0 AND 0 → 0 0 AND 1 → 0 1 AND 0 → 0 1 AND 1 → 1
Linearly Separable두 Class를 하나의 직선(고차원에서는 Hyperplane)으로 나눌 수 있다는 뜻입니다.

AND는 Output 1인 점이 (1,1) 하나뿐이라 직선 하나로 0과 1을 나눌 수 있습니다.

즉, 단순한 Linear Model 하나로도 표현 가능한 문제입니다.
11

XOR Gate — 직선 하나로는 구분할 수 없는 문제

XOR: (0,1), (1,0)은 1이고 (0,0), (1,1)은 0입니다. 같은 Class가 대각선으로 떨어져 있기 때문에 직선 하나로는 분리할 수 없습니다.
12

그럼 Linear Layer를 여러 개 쌓으면 XOR를 풀 수 있을까?

13

Activation이 없으면 깊어져도 표현력은 늘어나지 않습니다

h₁ = W₁x + b₁ h₂ = W₂h₁ + b₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W*x + b*

Layer를 2개, 10개, 100개 쌓아도 중간에 비선형 함수가 없다면 결국 하나의 Affine Layer와 같습니다.

그래서 XOR처럼 비선형 결정 경계가 필요한 문제는 Linear Layer만 쌓아서는 표현할 수 없습니다.
14

Activation Function이 비선형성을 추가합니다

Activation FunctionLinear / Convolution Layer 사이에 비선형 변환을 넣어 복잡한 함수를 표현할 수 있게 합니다.
ReLU(x) = max(0, x) [-2, -0.5, 0, 1, 3] ↓ [ 0, 0, 0, 1, 3]
Linear ↓ ReLU ↓ Linear ↓ ReLU ↓ 복잡한 Decision Boundary
비선형성이 들어가면서 단순한 직선 하나가 아니라 여러 영역을 조합한 복잡한 판단 경계를 만들 수 있습니다.

Train / Validation / Test의 역할은 다릅니다

TRAIN

문제집

정답을 보며 Weight를 실제로 학습합니다.

VALIDATION

모의고사

모델 선택, Hyperparameter 조정, Overfitting 확인에 사용합니다.

TEST

최종 시험

가능한 한 마지막까지 보지 않고 일반화 성능을 평가합니다.

Validation을 계속 보며 선택하면 Validation에도 맞춰집니다. 그래서 최종 Test는 별도로 유지하는 것이 중요합니다.
21

Data Leakage — 모델이 “보면 안 되는 정보”를 미리 본 경우

Validation/Test 성능은 좋아 보이지만 실제 새로운 데이터에서는 성능이 떨어질 수 있어, 모델 평가를 가장 크게 왜곡하는 원인 중 하나입니다.

① 같은 원본이 양쪽 Split에 존재

예: 한 영상에서 뽑은 인접 Frame 일부는 Train, 일부는 Validation에 들어감. 거의 같은 장면을 이미 본 상태가 됩니다.

② 전체 데이터로 전처리 기준 계산

Normalization, Feature Selection 등의 통계를 Train뿐 아니라 Validation/Test까지 포함해 계산하면 미래 정보가 학습에 섞입니다.

③ Test를 보며 모델을 계속 선택

Test 결과를 보고 Threshold나 Hyperparameter를 반복 조정하면 Test가 사실상 Validation 역할을 하게 됩니다.

원칙: Split 이후에는 각 단계가 접근할 수 있는 데이터를 명확히 제한해야 합니다.
22

이미지·영상은 Random Split보다 “원본 단위 분리”가 중요할 때가 많습니다

서로 매우 비슷한 Frame이 다른 Split으로 섞이지 않도록 영상·설비·대상·시간 같은 Group 단위로 나누는 것이 안전합니다.

Frame 수가 많아 보여도 같은 원본에서 나온 데이터라면 독립적인 Sample이라고 보기 어렵습니다.
23

K-Fold Cross Validation — 검증 대상을 바꿔가며 반복 평가

데이터를 K개 Fold로 나누고, 매번 하나를 Validation으로 사용해 K번 학습합니다. 평균뿐 아니라 Fold 간 변동도 함께 봅니다.

Fold 1VALTRAINTRAINTRAINTRAIN
Fold 2TRAINVALTRAINTRAINTRAIN
Fold 3TRAINTRAINVALTRAINTRAIN
Fold 4TRAINTRAINTRAINVALTRAIN
Fold 5TRAINTRAINTRAINTRAINVAL
최종 Test Set은 Cross Validation 바깥에 별도로 유지하는 것이 일반적

이미지·영상처럼 Group 상관관계가 강하면 일반 K-Fold 대신 Group K-Fold처럼 Group을 통째로 이동시키는 방식이 더 적절할 수 있습니다.

24

LOO — 하나만 남기고 나머지 전부로 학습

Leave-One-Out은 N개 Sample이 있다면 매번 1개만 Validation으로 두고 N번 반복하는 Cross Validation의 극단적인 형태입니다.

Run 1VALTRAINTRAINTRAINTRAINTRAIN
Run 2TRAINVALTRAINTRAINTRAINTRAIN
…TRAINTRAIN…TRAINTRAINVAL
장점매 학습에서 거의 모든 데이터를 Training에 사용합니다. 데이터가 매우 적을 때 검토할 수 있습니다.
단점N번 학습해야 하므로 계산량이 크고, 이미지·영상처럼 Sample 간 상관관계가 강한 데이터에는 Group 설계를 먼저 고려해야 합니다.
25

목표는 Train 점수가 아니라 “새로운 데이터에서의 성능”입니다

Overfitting과 Leakage를 피하고, 보지 못한 데이터에서도 성능이 유지되는 Generalization을 확인해야 합니다.
