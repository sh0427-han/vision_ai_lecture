AI는 어떻게 데이터에서 규칙을 배울까?

학습의 기본 원리부터 데이터 준비·평가·추론까지, Vision AI를 이해하는 데 필요한 AI 기초 흐름을 연결합니다.

문제 정의 → Model 계산 → Training → Evaluation → Inference
1

AI, Machine Learning, Deep Learning은 어떻게 다를까?

Computer Vision은 이미지·영상 문제를 다루는 분야이고, 그 문제를 해결하기 위해 전통적 영상처리, Machine Learning, Deep Learning을 모두 사용할 수 있습니다.
2

규칙을 사람이 직접 쓰는 것 vs 데이터에서 배우는 것

3

지도학습은 Label로 관계를 배우고, 비지도학습은 데이터 구조를 찾습니다

Supervised Learning(지도학습)은 입력과 Target Label의 관계를 학습하고, Unsupervised Learning(비지도학습)은 Label 없이 Feature Space의 구조·군집·Representation을 찾습니다.

Vision AI 예: Classification · Detection · Segmentation의 정답 Label로 학습하면 지도학습, Label 없이 비슷한 Image를 묶거나 Representation을 찾으면 비지도학습입니다.
4

Classification은 범주, Regression은 연속값을 예측합니다

둘 다 대표적인 지도학습 Task입니다. Classification은 유한한 Class 중 하나를 고르고, Regression은 실수 범위의 연속적인 값을 예측합니다.

5

6

가장 단순한 Model 계산부터 시작해 봅시다: Perceptron

입력 Feature마다 Weight를 곱하고, 모두 더한 뒤 Bias와 Activation을 적용해 하나의 Output을 만듭니다.

7

Weight와 Bias는 Model이 판단하는 방식을 결정합니다

Weight는 각 입력을 얼마나 중요하게 볼지, Bias는 전체 판단 기준을 어디에 둘지 조절합니다.

8

9

Perceptron 하나로 가능한 문제와 어려운 문제를 비교해 봅시다

AND와 XOR의 네 가지 입력을 좌표에 놓으면, 왜 더 복잡한 Network가 필요한지 직관적으로 보입니다.

10

Perceptron 여러 개를 연결하면 Layer와 Neural Network가 됩니다

각 Layer는 앞에서 받은 숫자를 다시 조합해 다음 Layer에 전달합니다. 이 반복이 Deep Learning의 기본 구조입니다.

11

하지만 Linear 계산만 계속 쌓으면 표현력은 크게 늘지 않습니다

중간에 비선형성이 없다면 여러 Linear Layer는 결국 하나의 큰 Linear Transformation으로 합쳐질 수 있습니다.

12

Activation Function이 Network에 비선형성을 추가합니다

ReLU 같은 함수가 Layer 사이에 들어가면 Network는 직선 하나로 표현할 수 없는 더 복잡한 Pattern을 조합할 수 있습니다.

13

Layer가 깊어지면서 Pixel은 판단에 유용한 Representation으로 바뀝니다

초기 Layer는 Edge·색 변화처럼 단순한 Feature를, 뒤쪽 Layer는 여러 Feature를 조합한 더 추상적인 Representation을 만들 수 있습니다.

14

이제 “좋은 Parameter를 찾는 과정”을 가장 단순한 예제로 보겠습니다

Linear Regression에서는 데이터에 가장 잘 맞는 직선을 찾습니다. 이때 Model이 학습하는 Parameter는 기울기 w와 절편 b입니다.

Linear Regression Model
y^ = wx + b
x 입력 y^ 예측값 w 기울기 b 절편
처음에는 임의의 w, b에서 시작하고, 예측 오차가 줄어들도록 두 Parameter를 반복해서 수정합니다.
15

좋은 Parameter인지 판단하려면 “얼마나 틀렸는지” 숫자로 표현해야 합니다

Loss Function은 Prediction과 Target의 차이를 학습에 사용할 수 있는 하나의 숫자로 만듭니다.

Regression의 대표 예: MSE(Mean Squared Error)는 여러 Sample의 (Target − Prediction)²을 평균냅니다. 수식보다 먼저 “Loss가 작을수록 현재 Parameter가 더 잘 맞는다”를 이해하면 됩니다.
16

Loss를 줄이려면 Parameter를 어느 방향으로 바꿀지 알아야 합니다

Gradient(기울기)는 현재 위치에서 Parameter를 움직였을 때 Loss가 어느 방향으로 변하는지 알려줍니다.

17

Optimizer는 Gradient를 이용해 실제로 Parameter를 Update합니다

Gradient의 반대 방향으로 조금씩 움직이면서 Loss가 낮은 Parameter를 찾습니다. Learning Rate는 한 번에 이동하는 크기입니다.

새 Parameter=현재 Parameter−Learning Rate × Gradient
18

이제 Training 전체 과정을 한 번에 연결해 봅시다

한 Batch마다 Prediction을 만들고, 틀린 정도를 계산하고, Gradient를 구한 뒤 Weight를 수정합니다.

19

Backpropagation은 각 Weight가 Loss에 미친 영향을 뒤에서부터 계산합니다

Forward에서 Prediction과 Loss를 만든 뒤, Backward에서 각 Layer의 Gradient를 계산합니다.

20

Training과 Inference의 가장 큰 차이는 Weight를 바꾸는가입니다

Training에서는 Label과 Loss를 이용해 Weight를 수정하고, Inference에서는 학습된 Weight를 고정한 채 새로운 Input의 Prediction만 계산합니다.

21

Dataset 전체를 한 번에 넣지 않고 작은 Batch로 나누어 반복 학습합니다

Batch, Iteration, Epoch은 “얼마나 많은 데이터를 어느 단위로 반복해서 보는가”를 설명하는 용어입니다.

22

Dataset은 모델이 배우는 “세상”입니다

모델은 Dataset에 없는 현실을 직접 알 수 없습니다. 양보다 먼저 “실제 운영 환경을 제대로 대표하는가?”를 봐야 합니다.

24

Data Augmentation은 “달라도 같은 의미”인 변화를 학습에 보여줍니다

실제 현장에서 생길 수 있는 변화 범위 안에서 이미지를 변형해, 모델이 특정 Pixel 조건만 외우는 것을 줄일 수 있습니다.

25

Train / Validation / Test는 서로 다른 역할을 맡습니다

Train은 Weight 학습, Validation은 모델·설정 선택, Test는 마지막 일반화 평가에 사용합니다.

26

28

Data Leakage는 평가할 때 몰라야 하는 정보가 새어 들어간 경우입니다

Validation/Test 성능이 실제보다 좋아 보일 수 있기 때문에 Split 이후의 정보 흐름을 엄격히 관리해야 합니다.

29

이미지·영상은 Random Frame Split보다 원본 단위 분리가 안전합니다

같은 영상·설비·대상·시간대에서 나온 Sample은 서로 강하게 연관되어 있을 수 있습니다.

30

K-Fold는 Validation 대상을 바꿔가며 성능이 안정적인지 확인합니다

한 번의 Train/Validation 분리에만 의존하지 않고 여러 번 반복해 평균 성능과 Fold 간 변동을 함께 봅니다.

영상·설비·환자처럼 서로 연관된 Sample이 있다면 Group K-Fold를 사용해 같은 Group이 Train과 Validation에 동시에 들어가지 않게 합니다.
31

Train을 잘하는 것과 새로운 데이터에서 잘하는 것은 다릅니다

Train에 지나치게 맞는 Overfitting을 피하고, 보지 못한 데이터에서도 성능이 유지되는 Generalization을 확인해야 합니다.

32

실제 AI 개발은 운영 결과를 다시 Data로 연결하는 반복 Cycle입니다

Training 한 번으로 끝나는 것이 아니라, Deploy 후 실패 사례를 Monitor하고 다음 Dataset과 학습에 반영합니다.
