Lecture 04 · Vision Transformer

이미지를 Token으로 바라보기

Transformer를 이미 안다는 가정 없이 Patch → Token → Embedding → Position → Q/K/V → Self-Attention 순서로 따라갑니다.

1

Transformer의 출발점: Token 사이의 관계

"I love vision AI" I → Token love → Token vision → Token AI → Token

이미지도 작은 조각으로 나눠 Token처럼 만들면 어떨까?

이 질문이 Vision Transformer를 이해하는 가장 좋은 출발점입니다.

2

Image → Patch

Patch이미지를 일정한 크기의 작은 정사각형 조각으로 나눈 단위입니다.
224 × 224 image ↓ 16 × 16 patch ↓ 14 × 14 ↓ 196 patches

224×224 이미지를 16×16 Patch로 나누면 196개의 조각이 됩니다.

3

Patch → Embedding → Token

16 × 16 × 3 = 768 values ↓ Flatten / Projection ↓ Embedding Vector
EmbeddingPatch를 일정 길이의 숫자 Vector로 바꾼 표현입니다.
TokenTransformer가 처리하는 기본 단위입니다. ViT에서는 각 Patch의 Embedding이 Token 역할을 합니다.
Token은 “이미지 조각 그 자체”보다 Transformer가 처리할 수 있게 바뀐 숫자 표현에 가깝습니다.
4

위치를 알려주는 Position Embedding

Patch Embedding + Position Embedding = Input Token
Position Embedding각 Token이 원래 이미지의 어느 위치에서 왔는지를 알려주는 숫자 Vector입니다.
CNN은 공간 구조가 연산에 자연스럽게 들어가지만, Transformer는 Token 순서만으로는 원래 2D 위치를 충분히 알 수 없기 때문에 위치 정보를 추가합니다.
5

CLS Token: 전체 이미지를 대표하는 자리

[CLS], Patch1, Patch2, ... Patch196 196 + 1 = 197 tokens
CLS TokenClassification용 ViT에서 여러 Patch 정보를 모아 최종 이미지 판단에 사용하는 특별한 Token입니다.

모든 Vision Transformer가 반드시 CLS Token을 사용하는 것은 아닙니다.

6

Self-Attention: 다른 Patch를 얼마나 참고할까?

현재 Token ↓ 모든 Token과 관련도 계산 ↓ 중요한 Token 정보는 많이 덜 중요한 Token 정보는 적게 ↓ 새로운 Token Feature

각 Token이 다른 Token의 정보를 선택적으로 섞어 새로운 Feature를 만듭니다.

7

Q, K, V는 무엇인가?

용어쉬운 비유실제 역할
Query (Q)나는 어떤 정보를 찾고 있나?다른 Key와 관련도를 계산할 Vector
Key (K)나는 어떤 특징을 가지고 있나?Query와 비교되는 Vector
Value (V)내가 전달할 정보는 무엇인가?Attention Weight로 가중합되는 실제 정보
Q/K/V는 모두 각 Token에서 학습 가능한 Linear Projection으로 만들어지는 숫자 Vector입니다.
8

Attention 계산

Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V
A → B : 0.10 A → C : 0.60 A → D : 0.20 A → E : 0.10
Q와 모든 K 비교 ↓ Score ↓ Softmax ↓ Attention Weight ↓ V 가중합

처음에는 수식보다 “비교 → Weight → Value 가중합” 흐름을 이해하는 것이 중요합니다.

9

Multi-Head Attention과 Transformer Encoder

Multi-Head Attention서로 다른 Q/K/V Projection을 가진 여러 Attention Head를 병렬로 사용합니다.
Tokens ├─ Head 1 ├─ Head 2 ├─ Head 3 └─ ...
Input Tokens ↓ LayerNorm ↓ Multi-Head Attention ↓ Residual ↓ MLP ↓ Residual ↓ Output Tokens
10

Patch 크기에는 Trade-off가 있습니다

224×224, Patch 16 → 14×14 → 196 tokens → 196² = 38,416
224×224, Patch 8 → 28×28 → 784 tokens → 784² = 614,656
Patch가 작으면 세밀한 정보를 더 유지할 수 있지만 Token 수가 늘고, 기본 Self-Attention의 계산량도 빠르게 증가합니다.
11

CNN vs Vision Transformer

CNN
작은 영역의 패턴을 반복적으로 추출하며 Local → Wider Context로 확장합니다.
ViT
이미지를 Patch Token으로 만들고 Token 사이 관계를 Self-Attention으로 학습합니다.
