Vision AI Study & Lecture

컴퓨터는 이미지를 어떻게 이해할까?

이미지를 숫자로 보는 것부터 CNN의 Convolution, Vision Transformer의 Patch와 Self-Attention까지. 처음 접하는 사람도 흐름을 놓치지 않도록 용어와 수치 예제를 함께 설명합니다.

학습 순서

어려운 모델 이름부터 외우지 않습니다. 먼저 이미지 데이터의 성질을 이해하고, CNN과 ViT가 그 데이터를 어떻게 표현으로 바꾸는지 따라갑니다.

01

Vision AI 입문

Pixel, RGB, Tensor와 조명·각도 변화가 왜 어려운지 이해합니다.

 02

CNN

Kernel, Convolution, Feature Map, Receptive Field를 단계적으로 봅니다.

 03

Vision Transformer

Patch, Token, Embedding, Q/K/V와 Self-Attention을 처음부터 설명합니다.

CNN과 ViT의 출발점

둘 다 이미지에서 유용한 Feature를 만들지만, 그 Feature를 만드는 기본 연산이 다릅니다.

CNN은 주변의 작은 영역부터 점점 넓혀가며 봅니다.
ViT는 이미지를 Patch Token으로 바꾸고 Token 사이의 관계를 Self-Attention으로 계산합니다.

강의자료 작성 원칙

입력 → 처리 → 출력

모델 이름보다 실제 데이터가 어떻게 흐르는지를 먼저 설명합니다.

수치 예제

224×224, 16×16 Patch, 196 Token처럼 숫자로 직접 계산합니다.

용어를 먼저 정의

Patch, Token, Embedding 같은 단어를 설명 없이 사용하지 않습니다.
