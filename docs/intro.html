Lecture 01 · Vision AI Introduction

AI는 세상을 어떻게 볼까?

사람에게 자연스러운 “보는 것”도 컴퓨터에게는 수많은 숫자에서 의미를 찾는 문제입니다.

이 이미지는 무엇으로 보이나요?

우리는 픽셀 값을 하나씩 계산하지 않아도 거의 즉시 “사과”라는 의미를 인식합니다.

1

사람은 “사과”를 보고, 컴퓨터는 RGB 숫자 배열을 봅니다

사람은 전체 형태와 의미를 한 번에 인식하지만, 컴퓨터가 처음 받는 것은 위치별 R · G · B 값이 쌓인 3차원 배열입니다.

2

Pixel 하나는 “위치 + R · G · B 값”입니다

Pixel은 이미지의 한 위치입니다. 일반적인 8-bit RGB 이미지에서는 각 위치에 Red · Green · Blue 세 값이 있고, 각 Channel 값은 보통 0~255 범위입니다.

3

이미지에는 Signal과 Noise가 함께 들어옵니다

Signal은 목표 판단에 도움이 되는 반복적인 구조·패턴이고, Noise는 목표와 관계없이 흔들리거나 우연히 섞이는 변화입니다. 컴퓨터 입력에서는 둘 다 Pixel 값으로 들어옵니다.

01Noise only
구조: 일정한 사과 형태가 없음
02Signal + Noise
혼합: 사과 구조 위에 무작위 변화가 겹침
03Signal clearer
Signal: 윤곽 · 색 · 형태 Pattern이 분명함
Signal 정답과 관계 있는 Pattern 예: 사과의 윤곽, 둥근 형태, 표면 질감
Noise 정답과 무관하게 변하는 값 예: 센서 잡음, 반사, 우연한 배경 변화
Learning goal Noise보다 Signal에 반응하는 규칙을 찾기

현장의 질문은 “무엇을 출력해야 하는가?”로 바뀝니다

같은 Vision AI라도 문제의 목적에 따라 Classification · Detection · Segmentation 중 적절한 Task를 선택합니다.

Classification 제품 전체 정상 / 불량 이미지 전체를 하나의 상태로 판단
Detection 결함이 어디에 있는가? 불량 위치와 개수를 Box로 찾음
Segmentation 결함 영역이 얼마나 넓은가? Pixel Mask로 면적과 형상을 측정
Detection 사람 · 차량 · 장애물 위치 장면 안의 여러 객체 위치를 찾음
Segmentation 의료 영상의 관심 영역 병변이나 장기의 경계를 Pixel 단위로 구분
Classification 장면 · 문서 · 품목 종류 전체 이미지가 어느 Category인지 판단
9

센서가 다르면 컴퓨터가 받는 숫자의 의미도 달라집니다

RGB Camera는 색·밝기, LiDAR는 거리 기반 3D Point, IR Camera는 적외선 강도 또는 열 정보를 측정합니다. 모두 숫자 데이터지만 물리적으로 의미하는 값은 다릅니다.
