Vision AI 입문

사람에게는 사진이지만, 컴퓨터에게는 숫자 배열입니다.

컴퓨터가 보는 이미지

224 × 224 RGB Image ↓ 224 × 224 × 3 Tensor ↓ 150,528 numeric values
Pixel 이미지의 가장 작은 단위입니다. RGB 이미지에서는 한 Pixel이 R, G, B 세 값으로 표현됩니다.
Tensor 딥러닝에서 이미지, Batch, Feature Map 등을 담는 다차원 숫자 배열입니다.

왜 같은 물체를 알아보기 어려울까?

같은 제품이라도 조명, 회전, 카메라 각도, 거리, 가림, Blur가 바뀌면 Pixel 값은 크게 달라집니다.

같은 물체 ↓ 밝기 / 위치 / 회전 / 배경 변화 ↓ 서로 다른 Pixel 배열 ↓ 그래도 같은 의미를 찾아야 함

대표 Vision Task

Task질문출력
Classification무엇인가?Class probability
Detection무엇이 어디에 있는가?Class + Bounding Box
Segmentation정확히 어느 Pixel인가?Pixel Mask
다음 질문은 자연스럽습니다. 수많은 Pixel에서 어떻게 유용한 특징을 찾을까? 이 질문에 대한 대표적인 답이 CNN입니다.
