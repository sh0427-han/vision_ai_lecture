Lecture 01

Vision AI 입문

모델 구조부터 시작하지 않습니다. 먼저 현실 세계가 센서를 통해 어떤 숫자로 바뀌고, 왜 그 숫자에서 의미를 찾는 일이 어려운지를 이해합니다.

1. Vision AI란?

Vision AI는 이미지나 영상, 거리 지도, 3차원 Point Cloud 같은 시각 데이터를 이용해 장면의 의미를 추출하는 AI 기술입니다. 무엇인지 분류하는 것뿐 아니라 위치, 형태, 움직임, 거리, 이상 여부를 판단하는 문제까지 포함합니다.

2. Vision 정보는 어디에서 얻을까?

RGB Camera가시광의 색과 밝기를 Pixel 형태로 기록합니다. 가장 익숙한 일반 카메라입니다.
Mono Camera색보다 밝기 정보를 중심으로 기록합니다. 산업 검사에서는 높은 감도나 단순한 형상 분석에 유리한 경우가 있습니다.
IR / NIR사람의 눈에 보이지 않는 적외선 영역을 이용해 야간이나 특정 재질 특성을 관찰합니다.
Thermal Camera열 복사를 기반으로 온도 분포를 영상처럼 표현합니다.
Depth Camera각 Pixel에 색 대신 또는 색과 함께 거리를 저장합니다. Stereo나 ToF가 대표적인 깊이 측정 방식입니다.
LiDAR레이저를 이용해 3차원 거리 정보를 얻으며, 결과를 Point Cloud로 표현하는 경우가 많습니다.
Event Camera정해진 FPS로 전체 Frame을 찍기보다 각 Pixel의 밝기 변화가 발생할 때 비동기 Event를 출력합니다.

3. 사람에게 사진, 컴퓨터에게 숫자

Pixel 디지털 이미지를 구성하는 작은 위치 단위입니다. RGB 영상에서는 한 Pixel에 보통 R, G, B 세 Channel 값이 있습니다.
Channel 한 Pixel이 갖는 정보의 축입니다. RGB는 3 Channel이고, Gray Image는 보통 1 Channel입니다.
Tensor 딥러닝에서 이미지와 Feature를 담는 다차원 숫자 배열입니다. PyTorch에서는 이미지 Batch가 흔히 B×C×H×W 형태입니다.

수치 예시

1920 × 1080 RGB Image ↓ 1920 × 1080 × 3 ↓ 6,220,800 channel values / frame 30 FPS ↓ 186,624,000 channel values / second

4. 그런데 왜 이미지 인식은 어려울까?

사람은 조명이 조금 바뀌어도 같은 컵이라고 쉽게 판단합니다. 하지만 컴퓨터 입장에서는 Pixel 값이 직접 달라집니다.

같은 물체 ↓ 조명 / 시점 / 크기 / 회전 / 가림 / Blur / 배경 ↓ 서로 다른 숫자 배열 ↓ 그래도 같은 의미를 찾아야 함

예를 들어 밝은 환경의 한 Pixel이 [180, 170, 165]였다가, 어두운 환경에서는 [80, 75, 72]가 될 수 있습니다.

5. Vision AI는 어떤 질문에 답할까?

Task질문대표 출력
Classification이 이미지가 무엇인가?Class Probability
Object Detection무엇이 어디에 있는가?Class + Bounding Box
Segmentation정확히 어느 Pixel이 물체인가?Pixel Mask
Tracking시간에 따라 어디로 움직이는가?ID + Trajectory
Depth / 3D얼마나 멀고 어떤 공간인가?Depth / 3D Geometry

6. 결국 모델은 무엇을 배우는가?

입력 숫자를 그대로 비교하기보다, 판단에 필요한 Feature를 만들어야 합니다. 여기서부터 CNN과 Vision Transformer가 등장합니다.

Raw Sensor Data ↓ Feature Extraction ↓ Representation ↓ Classification / Detection / Segmentation / Measurement
다음 질문은 “수백만 개의 숫자에서 어떻게 유용한 Feature를 만들까?”입니다. CNN은 작은 지역의 패턴을 반복적으로 추출하는 방식으로 이 문제를 풀기 시작합니다.
