01 · 문제 정의 기본 개념

필요한 결과부터 정하면 Vision Task가 정해집니다

이미지 전체가 불량인지, 결함이 어디에 있는지, 정확한 면적이 얼마인지에 따라 필요한 결과가 다릅니다.

질문 → 결과 형태 → Task → Label → 평가 기준과 모델 순으로 연결합니다.

02 · Classification 기본 개념

이미지 전체의 상태나 종류를 예측합니다

Classification(분류)은 이미지 단위의 클래스와 점수를 출력합니다. 아래 예시는 사과 사진 전체의 불량 여부입니다.

이 예시는 단일 Label 분류입니다. 위치나 정확한 결함 영역은 출력하지 않습니다.

03 · Object Detection 기본 개념

객체나 결함의 위치를 사각형으로 찾습니다

Object Detection(객체 검출)은 클래스·Bounding Box(경계 상자)·점수를 출력합니다.

Box 내부 전체가 결함인 것은 아닙니다. 상자는 위치를 둘러싸는 표현입니다.

04 · Segmentation 기본 개념

어느 Pixel이 관심 영역인지 구분합니다

Segmentation(분할)은 Pixel별 클래스나 Mask(영역 표시)를 출력합니다. 아래 예시는 결함 영역입니다.

형상·면적·경계가 필요하면 Box보다 Mask가 적합합니다.

05 · Label 기본 개념

같은 사진이라도 Task가 바뀌면 정답 형태가 바뀝니다

분류는 이미지 클래스, 검출은 클래스와 Box, 분할은 Pixel Mask를 정답으로 사용합니다.

여기서 결과 그림을 정답으로 작성한 것이 Label이고, 모델이 계산한 것이 Prediction입니다.

06 · IoU 기본 개념

위치와 영역은 정답과 얼마나 겹치는지 평가합니다

IoU(Intersection over Union, 교집합/합집합 비율)는 정답 영역과 예측 영역의 겹침 정도입니다.

완전 일치하면 1, 겹치는 영역이 없으면 0입니다.

07 · IoU 상세 설명

겹친 칸 수를 전체 합집합 칸 수로 나눕니다

정답 12칸과 예측 12칸이 4칸 겹치면, 합집합은 12+12−4=20칸입니다.

IoU = 4/20 = 0.2. 검출은 Box, 분할은 Mask의 영역으로 계산합니다.

개념 참고: Stanford CS231n · 직접 재구성한 설명용 Figure

08 · 영상처리의 기본 기본 개념

한 Pixel을 바꿀 수도, 주변 Pixel을 함께 볼 수도 있습니다

영상처리는 밝기·잡음·경계 같은 이미지의 성질을 바꿉니다. 같은 사과 사진으로 두 연산을 비교합니다.

밝기 변환은 해당 Pixel 값으로 계산하고, 필터는 주변 값도 사용합니다. 이 연산 자체가 물체 이름을 예측하지는 않습니다.

참고: Szeliski · Ch. 3 §3.1–3.2 · 기존 AI 생성 사진 / 합성 데이터에 실제 연산 적용

09 · Gaussian 필터 기본 개념

잡음을 줄이면 작은 변화도 함께 흐려질 수 있습니다

Gaussian(가우시안) 필터는 가까운 Pixel에 큰 가중치를 주어 평균합니다. σ(시그마)는 퍼짐의 정도를 정합니다.

σ는 원본 Pixel 단위입니다. 잡음 감소와 작은 결함 보존을 함께 확인하고, 실제 Task의 평가 결과로 전처리를 선택합니다.

참고: Szeliski · Ch. 3 §3.2.2 · 기존 AI 생성 사진 / 합성 데이터에 실제 연산 적용

10 · 평균 필터 계산 상세 설명

주변 9개 값을 평균해 출력 한 칸을 계산합니다

3×3 평균 필터의 각 가중치는 1/9입니다. 가운데의 큰 값 160도 주변 8개 값과 함께 계산합니다.

평균 필터는 사람이 정한 고정 가중치입니다. CNN은 같은 가중합 구조의 필터 값을 데이터에서 학습할 수 있습니다.

참고: Szeliski · Ch. 3 §3.2 · 기존 AI 생성 사진 / 합성 데이터에 실제 연산 적용

11 · 중앙값 필터 기본 개념

튀는 점 잡음에는 중앙값이 유용할 수 있습니다

Median(중앙값) 필터는 이웃 값을 정렬해 가운데 값을 선택합니다. 같은 점 잡음 입력에서 평균 필터와 비교합니다.

중앙값은 선형 가중합이 아닌 비선형 연산입니다. 얇은 선이나 작은 결함도 없어질 수 있어 모든 잡음에 최선인 것은 아닙니다.

참고: Szeliski · Ch. 3 §3.3.1 · 기존 AI 생성 사진 / 합성 데이터에 실제 연산 적용

12 · 영상 기울기 기본 개념

밝기가 급격히 바뀌는 위치에서 경계 단서를 얻습니다

Sobel(소벨) 필터로 좌우·상하 밝기 변화를 계산합니다. 부호 있는 값을 계산한 뒤 절댓값과 크기로 시각화합니다.

두 기울기 그림은 같은 최대값으로 표시했습니다. 경계 반응은 밝기 변화의 단서이며, 그 자체가 물체나 결함의 정답은 아닙니다.

참고: Szeliski · Ch. 3 §3.2.1–3.2.2 · 기존 AI 생성 사진 / 합성 데이터에 실제 연산 적용

13 · Mask 후처리 기본 개념

작은 점 제거와 작은 구멍 메우기는 다른 연산입니다

Morphology(형태학)는 구조 요소로 Mask의 모양을 처리합니다. 침식은 1 영역을 줄이고, 팽창은 1 영역을 넓힙니다.

Opening·Closing은 원래 Mask를 각각 처리한 결과입니다. 작은 실제 결함이 지워지거나 가까운 영역이 붙을 수 있어 크기를 검증해야 합니다.

참고: Szeliski · Ch. 3 §3.3.2 · 기존 AI 생성 사진 / 합성 데이터에 실제 연산 적용

14 · 이미지의 단서 기본 개념

작은 영역의 경계·밝기 변화를 먼저 살펴봅니다

이미지에서는 가까운 Pixel의 배치가 중요합니다. 작은 영역의 반응을 여러 위치에서 계산하면 패턴이 있는 위치를 알 수 있습니다.

Patch는 이미지의 작은 영역, Feature Map은 위치별 반응값을 모은 지도입니다.

15 · CNN 기본 개념

CNN은 작은 영역을 보고 같은 가중치를 재사용합니다

Convolutional Neural Network(합성곱 신경망)는 지역 연결과 가중치 공유로 이미지의 공간적 패턴을 계산합니다.

Flatten은 값과 순서를 유지하지만, 완전연결층에는 공간 이웃 관계와 가중치 공유가 명시되어 있지 않습니다.

16 · Kernel 기본 개념

같은 필터도 이미지 영역에 따라 반응이 달라집니다

Kernel 또는 Filter(커널·필터)는 작은 가중치 배열입니다. 세로 밝기 변화가 있는 영역과 평평한 영역의 반응을 비교합니다.

그림은 사람이 정한 경계 필터 예시입니다. CNN의 필터 값은 학습으로 정해집니다.

17 · Convolution 상세 설명

같은 위치끼리 곱하고 더해 출력 한 칸을 만듭니다

입력의 3×3 영역과 필터를 곱해 합산하고, 필터를 옮겨 다음 칸을 계산합니다. 모든 출력은 실제 계산한 값입니다.

이 장은 한 채널·Bias 0 예시입니다. 일반적인 딥러닝 Conv는 필터를 뒤집지 않는 Cross-correlation 연산입니다.

개념 참고: Stanford CS231n · 직접 재구성한 설명용 Figure

18 · Feature Map 기본 개념

반응값을 위치대로 모으면 특징 지도가 됩니다

서로 다른 필터는 서로 다른 위치에서 반응합니다. 여러 반응 지도를 쌓은 것이 출력 Channel(채널)입니다.

이 그림은 설명용 예시입니다. 실제 학습된 Channel의 의미는 항상 사람이 이름 붙일 수 있지는 않습니다.

19 · Feature Map과 Channel 상세 설명

RGB 전체를 보는 필터 하나가 출력 Channel 하나를 만듭니다

일반적인 Conv2d에서 필터 하나는 입력 Channel 전체를 곱해 합산합니다. 출력 Channel 수는 필터 수입니다.

224×224×3 입력, 64개 필터, Stride 1·Padding 1이면 224×224×64가 됩니다.

개념 참고: Stanford CS231n · 직접 재구성한 설명용 Figure

20 · Stride 기본 개념

필터를 몇 칸씩 이동할지 정합니다

Stride(이동 간격)가 1이면 한 칸, 2이면 두 칸씩 이동합니다. 같은 입력과 필터에서 이동 간격이 크면 출력 크기가 작아집니다.

5×5 입력과 3×3 필터, Padding 0: Stride 1은 3×3, Stride 2는 2×2 출력입니다.

21 · Padding 기본 개념

가장자리 주변에 값을 채워 계산 범위를 조절합니다

Padding(패딩)은 입력 주위를 채우는 방법입니다. 아래는 가장자리 한 칸에 0을 채우는 Zero Padding입니다.

5×5 입력, Kernel 3·Stride 1·Padding 1이면 출력의 공간 크기가 5×5로 유지됩니다.

22 · Downsampling 기본 개념

공간 해상도를 줄여 더 작은 특징 지도를 만듭니다

Downsampling(다운샘플링)은 가로·세로 크기를 줄이는 과정입니다. 아래는 2×2에서 최댓값을 남기는 Max Pooling 예시입니다.

8×8 → 4×4는 위치 수가 64개에서 16개로 줄어듭니다. 작은 결함이나 경계의 위치 정보가 일부 사라질 수 있습니다.

23 · 이미지 피라미드 상세 설명

평활화 후 축소해 여러 해상도의 영상을 만듭니다

Gaussian Pyramid(가우시안 피라미드)는 평활화 후 가로·세로를 절반으로 줄입니다. 축소 전 평활화는 Aliasing(가짜 패턴)을 줄이는 데 쓰입니다.

사진의 Gaussian 피라미드와 CNN의 Max Pooling은 계산이 다릅니다. 가로·세로가 절반이면 Pixel 수는 1/4이 됩니다.

참고: Szeliski · Ch. 3 §3.5.2–3.5.3 · 기존 AI 생성 사진 / 합성 데이터에 실제 연산 적용

24 · 출력 크기 계산 상세 설명

Kernel·Stride·Padding으로 출력 크기를 계산합니다

H는 입력 높이, K는 필터 크기, S는 Stride, P는 양쪽 Padding입니다. floor는 소수점 아래를 버립니다.

Dilation 1 기준 식입니다. Channel 수는 공간 크기와 별도로 필터 수가 결정합니다.

개념 참고: Stanford CS231n · 직접 재구성한 설명용 Figure

25 · 특징의 조합 기본 개념

Layer는 앞의 특징을 조합해 더 복잡한 표현을 만듭니다

초기 반응들을 여러 층에서 조합하면 더 넓은 형태와 Task에 유용한 내부 표현을 만들 수 있습니다.

경계 → 부분 → 형태는 개념적 설명이며 모든 모델에서 같은 방식으로 나타난다고 보장하지 않습니다.

사진: AI 생성 교육용 예시 · 실제 측정/실험 결과가 아님

26 · Receptive Field 상세 설명

깊은 층의 한 위치는 더 넓은 입력 범위의 영향을 받습니다

Receptive Field(수용영역)는 한 출력 위치에 영향을 주는 원본 입력 영역입니다.

3×3 Conv, Stride 1, Dilation 1을 쌓으면 이론적 수용영역은 3×3 → 5×5 → 7×7입니다.

개념 참고: Stanford CS231n · 직접 재구성한 설명용 Figure

27 · CNN 전체 흐름 기본 개념

작은 연산들을 연결하면 이미지 분류기가 됩니다

224×224×3 입력을 특징 지도로 바꾸고, 전역 평균 풀링으로 요약한 뒤 분류 점수를 계산합니다.

H×W×C 순서의 설명용 작은 CNN입니다. 검출·분할 모델에는 위치를 보존하거나 복원하는 추가 구조가 필요합니다.

참고: Alzubaidi et al. (2021) · Fig. 7 · CNN layers · PyTorch Conv2d · 강의용 재구성

28 · Backbone과 Head 기본 개념

특징을 만드는 부분과, 결과를 만드는 부분을 나눠 봅니다

Backbone(백본)은 특징을 추출하고, Head(헤드)는 Task별 결과를 만듭니다. 입력과 결과는 동일한 사과 사진을 사용합니다.

세 가지 Head는 구조 비교를 위한 개념도입니다. 실제 한 모델이 항상 세 Task를 동시에 출력하는 것은 아닙니다.

블록을 연결하고 각 단계의 특징 크기를 표시합니다

Architecture(모델 구조)는 어떤 연산을 어떤 순서로 연결하는지 나타냅니다. 아래 크기는 구조를 설명하는 예시입니다.

30 · CNN 구조의 설계 기본 개념

순차·병렬·우회 연결로 서로 다른 구조를 만듭니다

VGG는 순차, Inception은 병렬, ResNet은 우회 연결을 사용합니다. 그림은 각 구조의 연결 원리입니다.

깊이만 늘리는 것 외에도 연결 방식이 중요합니다. 구조의 우열은 데이터·정확도·메모리·처리시간을 함께 검증해 결정합니다.

참고: Alzubaidi et al. (2021) · CNN architectures · VGG 원 논문 · 강의용 재구성

31 · Residual 연결 상세 설명

입력을 그대로 전달하는 경로와 변환 경로를 더합니다

Residual(잔차) 블록은 F(x)+x를 계산합니다. 56×56×64 입력을 더하려면 두 경로의 Tensor Shape가 같아야 합니다.

원소별 합산이며 Channel 결합과 다릅니다. ResNet v1은 합산 뒤 ReLU를 적용합니다. 우회 경로는 깊은 모델의 최적화를 돕습니다.

참고: Alzubaidi et al. (2021) · Fig. 20 · ResNet · ResNet 원 논문 · 강의용 재구성

32 · CNN 학습 기본 개념

CNN의 필터도 오차를 줄이는 방향으로 학습합니다

Forward로 예측하고 Label과 Loss를 비교한 뒤, Backpropagation으로 Gradient를 계산하고 Optimizer가 필터를 갱신합니다.

기본 학습 원리는 AI Basics와 같습니다. 학습하는 Parameter에 Kernel 가중치가 포함됩니다.

33 · Transfer Learning 기본 개념

이미 배운 가중치에서 내 Task의 학습을 시작합니다

Transfer Learning(전이학습)은 사전학습 모델의 지식을 재사용하는 방법입니다. 처음부터 모든 값을 새로 배우는 것과 비교할 수 있습니다.

내 데이터가 사전학습 데이터와 다르면 효과가 달라질 수 있으므로 별도 평가가 필요합니다.

34 · Freeze와 Fine-tuning 상세 설명

고정할 부분과 추가 학습할 부분을 구분합니다

Freeze는 가중치 고정, Fine-tuning(미세조정)은 사전학습 가중치 일부 또는 전체를 새 데이터로 업데이트하는 과정입니다.

36 · 운영 Cycle 기본 개념

성공 기준을 정하고 데이터를 모아 학습·평가·배포합니다. 운영의 실패 사례는 다음 데이터 보강의 근거가 됩니다.
