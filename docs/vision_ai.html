Lecture 03 · Vision AI

Vision AI의 대표 Task와 CNN을 연결해 봅니다

Classification · Detection · Segmentation의 Output과 Label 차이를 먼저 확인하고, CNN이 Pixel에서 Feature를 만드는 과정을 순서대로 살펴봅니다.

1

Vision AI는 모델보다 “원하는 Output”을 먼저 정합니다

현장 질문을 Output 형태로 바꾸면 Task와 Label 형태가 결정되고, 그 다음에 적절한 모델 구조를 선택할 수 있습니다.

2

Classification — 이 이미지가 무엇인가?

이미지 전체에 하나의 Class 또는 Probability를 출력합니다.

MetricAccuracy · Precision · Recall · F1
3

Object Detection — 무엇이 어디에 있는가?

여러 객체의 Class, 위치, Confidence를 함께 출력합니다.

MetricPrecision · Recall · IoU · mAP
4

Segmentation — 정확히 어느 Pixel인가?

관심 물체나 결함의 정확한 영역과 형상을 Pixel 단위로 구분합니다.

MetricIoU · Dice · Boundary IoU
5

Task가 달라지면 정답 Label의 형태도 달라집니다

같은 사과 이미지라도 무엇을 학습시키는지에 따라 정답 데이터의 구조가 달라집니다. 모델은 이 Label과 Prediction의 차이를 줄이도록 학습합니다.

6

CNN은 작은 영역의 Pattern을 조합해 Feature를 만듭니다

Convolutional Neural Network(CNN)는 이미지의 작은 지역에서 반복되는 반응을 찾고, Layer를 거치며 이를 더 복잡한 Feature로 조합합니다.

7

Kernel이 작은 영역을 훑으며 Convolution을 수행합니다

작은 Weight 배열인 Kernel(Filter)을 여러 위치에 같은 방식으로 적용해 특정 Local Pattern에 얼마나 반응하는지 계산합니다.

8

Stride와 Padding은 Feature Map의 크기와 정보 흐름을 바꿉니다

Stride는 Kernel이 이동하는 간격, Padding은 가장자리 주변을 채우는 방법입니다. 공간 크기를 줄이는 Downsampling은 계산량과 넓은 문맥 사용에 영향을 줍니다.

9

한 Kernel의 반응 결과가 Feature Map 하나가 됩니다

여러 Kernel을 사용하면 서로 다른 Pattern 반응이 여러 Feature Map으로 만들어지고, 이 Map들이 Channel 축으로 쌓입니다.

10

Layer가 깊어질수록 여러 Local Feature가 조합됩니다

초기 Layer의 단순한 반응이 뒤쪽 Layer에서 조합되며 더 복잡한 형태와 부분 구조를 표현할 수 있습니다.

11

Receptive Field가 커지면 더 넓은 문맥을 볼 수 있습니다

Receptive Field는 한 Feature가 원본 이미지에서 영향을 받는 영역입니다. Layer가 쌓이거나 Downsampling되면 더 넓은 범위의 정보를 함께 사용할 수 있습니다.

12

Kernel Weight도 Loss가 줄어드는 방향으로 학습됩니다

사람이 Edge Filter를 모두 직접 지정하는 것이 아니라, Prediction → Loss → Backpropagation을 통해 Task에 유용한 Kernel Weight가 업데이트됩니다.

13

많은 Vision Model은 Feature 추출부와 Task별 Head로 나눠 볼 수 있습니다

입문적으로는 Backbone을 공통 Feature 추출부, Head를 Task에 맞는 Output을 만드는 부분으로 이해하면 좋습니다.

14
