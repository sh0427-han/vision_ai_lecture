# Visual / Paper Sources

강의 자료의 출처와 사용 원칙을 기록합니다.

## 원칙

1. 논문 Figure를 그대로 복사하기보다 가능한 경우 직접 다시 그린 교육용 Diagram을 사용합니다.
2. 원 논문의 구조나 아이디어를 바탕으로 다시 그린 경우 해당 강의 문서에 원 논문 링크를 표시합니다.
3. 외부 사진을 추가할 경우 License와 원본 URL을 이 파일에 기록합니다.
4. 출처가 불명확한 이미지는 강의자료에 포함하지 않습니다.
