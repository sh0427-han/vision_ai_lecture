# Interactive Demos

강의 중 브라우저에서 바로 보여줄 수 있는 시각적 데모를 관리합니다.

## 계획

### 1. Lighting & Pixel Demo
마우스를 광원처럼 움직이면서 물체의 밝기와 Pixel Matrix가 동시에 변하는 데모.

핵심 메시지:
> 같은 물체라도 조명 조건이 달라지면 컴퓨터가 받는 숫자는 달라진다.

### 2. Feature Recognition Demo
같은 물체에서 색, 윤곽, 질감, 부분 특징을 차례로 강조해 사물을 판단하는 직관을 보여주는 데모.

### 3. Convolution Visualizer
3×3 Kernel이 이미지 위를 이동하면서 출력 Feature Map이 만들어지는 과정을 단계별로 표시.

### 4. CNN Feature Hierarchy
초기 Layer와 깊은 Layer의 Feature를 비교해 Local Pattern → Complex Feature 흐름을 시각화.
